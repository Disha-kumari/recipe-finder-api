# 🍳 Recipe Finder

## About

Recipe Finder is a Python-based application that uses
TheMealDB API to find recipes based on ingredients.

## Features

- Search recipes by ingredient
- Display available recipes
- Select a recipe
- View complete recipe information

## Technologies

- Python
- REST API
- JSON
- Requests
- Git
- GitHub

## API

TheMealDB API

## How to Run

pip install -r requirements.txt

python main.py
