# 🍳 Recipe Finder

## 📌 Description

Recipe Finder is a Python mini-project that uses the **TheMealDB API** to find recipes based on an ingredient entered by the user.

## ✨ Features

* Search recipes by ingredient
* Get recipe data using an API
* Display available recipes
* Select a recipe from the list

## 🛠️ Technologies Used

* Python
* Requests
* TheMealDB API
* Git
* GitHub

## 🔗 API Used

**TheMealDB API**

The project sends an ingredient to the API and receives recipe information in JSON format.

## 🚀 How to Run

### 1. Install the required library

```bash
pip install -r requirements.txt
```

### 2. Run the program

```bash
python main.py
```

### 3. Enter an ingredient

Example:

```text
Enter an ingredient: chicken
```

## 📌 Example Output

```text
🍳 Recipes Found:

1. Chicken Handi
2. Chicken Curry
3. Chicken Korma
```
